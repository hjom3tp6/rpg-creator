# Rule · Fail Forward (no dead ends)

Failure is a story, never a Game Over. Match the game's tone: in a comedy a setback is a funny new
hook; in a grim game it costs something real — but it still opens a path.

## Principles
- **Failure opens a branch, not a wall.** Botched stealth → you're caught → a new scene in a cell
  with a guard who wants something. Failed persuasion → you made an enemy who'll be back.
- **The signature mechanic can misfire in character.** If the game has a power or system (casting, a
  trade, a performance), a failure twists the result rather than voiding it — per its module ruling.
- **Relationships bend, they don't lock.** A cooled ally, a jealous flare, a clumsy line that lands
  wrong → an awkward beat the player can recover from, not a closed route. (Romance specifics:
  `module-library/romance.md`.)
- **"Death" becomes a turn.** If the player character's situation goes truly catastrophic, convert it
  (rescued, captured, a time skip, a rescue with strings attached) rather than ending the game —
  unless the player explicitly asks for hardcore stakes. Some structures make *other* losses permanent
  (a siege, a doomed cause); the story still continues.

## Drama dice (keep surprise alive)
Even without numbers, don't let outcomes be "all GM's whim." When an action's result is genuinely
uncertain (persuade a stubborn official, sneak past a guard, gamble), roll an invisible inner check
(success / partial / fail) weighted by the situation and the player's recent play & disposition,
then narrate from it. **Never show dice or probabilities** — only the dramatic result. Make failure
*interesting*.

## Fortune's Favor — the crit band (variable-ratio reward)
Outcomes aren't just success↔fail. Reserve a **rare top band**: now and then, an ordinary action pays
off *far* beyond what it should. This is the delight engine — unpredictable, oversized **good**
surprises the player didn't earn in a straight line, so the next attempt always *might* be the jackpot.

- **Rare but felt.** Roughly a once-in-many-actions thing, never every scene. Its power is scarcity —
  if it's common, it's wallpaper. When it lands, make it unmistakably a *gift*.
- **The jackpot is content, not just a bigger number.** A casual line lands a **key ally**; a throwaway
  search turns up **plot-critical intel** or a **codex jackpot** (unlock something hidden); a clumsy
  moment **spikes someone's disposition**; a small bet returns a windfall; an opponent's plan *happens*
  to unravel in the player's favor.
- **Weight it, don't fake it.** Nudge the odds up after a string of bad luck, a bold or clever play, a
  beautiful line, or when the player's been grinding without a win — so the gift feels *deserved-ish*
  and timely, not arbitrary. Down-weight it right after a recent crit.
- **Explain it the way the world would.** In a game built on a luck or hidden-power theme, the room
  reads the jackpot as coincidence (per that game's own lore rule); elsewhere it is simply fortune.
- **Still fail forward.** The crit band is the up-side of the same uncertainty that makes failure
  interesting; keep both alive so the world feels genuinely unpredictable, not GM-scripted.
