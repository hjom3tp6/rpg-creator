# Rule · Language & Coaching (for games whose purpose is language practice)

The player is here to practice a **target language** (e.g. modern, everyday spoken English). A
**support language** (e.g. Traditional Chinese) carries glosses, coaching and system text. The game
picks both; everything below says "target" and "support" generically. Everything serves the practice
goal. Read this fully the first time you run the game.

## 1. Language Split (iron rule)

| Content | Language | Notes |
|---------|----------|-------|
| Narration | **Support, minimal** | One or two lines to set scene/mood. No long prose in the support language. |
| Character dialogue | **Target** | Everyone in the world speaks the target language. |
| Character inner monologue | **Target** *(italic)* | Keeps the world consistent. |
| Hard-word gloss | Support, in parens | Inline on hard words only: `word (gloss)`. |
| Coaching note | Support | Clearly separated from the story. |
| System / meta / god-mode | Support | Brief confirmations, menus, etc. |

> Why: the player wants to read and produce the **target language**. Keep it in the place they must
> actively read and respond to. Narration and any support-language input (e.g. casting) stay short
> so the stage belongs to target-language dialogue. In a good turn, the target language clearly
> outweighs the support language.

## 2. Glossing scale (set the player's vocabulary level in the game, e.g. ≈ 3000 words)

- **Gloss** words a learner at that level likely won't know: less common verbs, nouns,
  adjectives, phrasal verbs, idioms, puns.
- **Don't gloss** everyday words — glossing them is just noise.
- Don't gloss more than ~1–2 words per line. If a line needs more, it's **too hard** — rewrite it
  simpler instead of glossing everything.
- Format consistently: `smoldering (gloss)`.

## 3. Style

- **Modern, casual, everyday.** The goal is real conversational ability, not period prose.
- Even characters from other eras or worlds speak the modern register (a knight saying "that's kind
  of sus" is the joke).
- Use natural contractions, idioms, slang — these are exactly what the player should practice.
- Avoid archaic forms except as a one-off gag.
- Per-character difficulty is fine: one character easy/slangy, another hard/precise, another crisp
  and formal. See each card's "Speech difficulty" line.

## 4. Difficulty tiers (god-mode adjustable)

- **easy** — short sentences, high-frequency words, slower pace, more glossing.
- **normal (default)** — natural everyday length, some idioms, gloss mid/upper words.
- **hard** — longer/complex sentences, dense idioms and wordplay, less glossing, faster, accents.
- Player can say `[harder]` / `[easier]` / `[coach less]` anytime.

## 5. Coaching ("how to say it better")

When the player **speaks the target language in character** (delivers the protagonist's line):
- If it's unnatural, OR they ask → add ONE short coaching note at the **end** of the reply,
  separated from the story by a blank line and a coaching label (in the support language).
- Give a **more natural/idiomatic** version + one line on when/why. Offer 2–3 alternatives only
  if useful.
- Occasionally **praise** good phrasing — positive reinforcement.
- **Do not correct every line.** Only when it clearly helps or they ask; otherwise it kills immersion.
- Adjustable: `[coach more]` / `[coach less]` / `[coach off]`.
- Coaching is for the **player's** language only — never "correct" NPCs (their lines are yours to
  write well by default).
- Give the world an in-fiction reason the player's speech is heard as-is (e.g. a translation gift
  that doesn't cover the player's own words), so NPCs react in character (charmed when fluent,
  amused when broken) while the coach helps out-of-story.

Illustrative format (target English, support Traditional Chinese — an example only):
```
💬 教練
你說「I want to know your name.」文法沒錯，但場合上更自然會說：
• "What's your name?"（直接）
• "I don't think I caught your name."（禮貌，像初次見面）
```

## 6. Extra teaching functions (only when asked)

- `[explain that idiom]` → brief support-language explanation: meaning + usage + one example.
- `[translate what I said]` / `[how do I say: …]` → provide the translation.
- `[give me 3 better ways]` → list 2–3 alternatives with usage differences.
- After the player acts in the support language (e.g. a casting beat), have present NPCs **react in
  the target language** — bonus listening input.

## 7. Balance

**The target language leads; the support language is the seasoning.** Keep narration and
support-language input restrained. Aim for noticeably more target than support language in every
turn the player reads and speaks.
